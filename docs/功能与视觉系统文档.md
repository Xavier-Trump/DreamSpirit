# DreamSpirit 功能与视觉系统文档

本文档描述当前 Next.js 全栈版本的实际页面、核心流程、交互状态和视觉系统。旧版计划中的 `home.html`、`create.html`、`detail.html` 等纯前端页面已经升级为 App Router 页面与服务端 API。

## 信息架构

```text
/                     入口页，按登录状态跳转
/sign-in              登录页
/sign-up              注册页
/app                  梦境总览
/dreams/new           新建梦境
/dreams/[id]          梦境详情、编辑与 AI 动作
/timeline             时间轴与筛选
/elements             梦境元素图谱
/insights             洞察报告
/community            共享梦境与公共宇宙
/settings             账号、导出、AI 与偏好设置
/exports/print        打印版梦境报告
```

登录后的页面统一由 `components/app-shell.tsx` 承载侧边导航、账号状态和主内容区域。

## 页面与功能

### 1. 入口、登录与注册

入口页根据用户状态进入应用或登录页。账号系统使用 Auth.js Credentials：

- 用户可注册邮箱账号。
- 密码通过 bcryptjs 哈希后保存。
- seed 提供体验账号，便于演示。
- 访客浏览模式只开放读取体验数据，写入动作会显示只读提示。


### 2. 梦境总览 `/app`

功能定位：展示用户梦境库的概况与最近记录。

主要内容：

- 总梦境数
- 已完成 AI 解析数
- 重复梦境数
- 最近记录列表
- 快捷入口：记录新梦境、查看洞察、浏览共享社区

卡片展示字段：

- 标题
- 梦境发生时间
- 内容摘要
- 情绪标签
- 清晰度
- 重复梦境标记
- 状态标签


### 3. 记录梦境 `/dreams/new`

功能定位：把梦境快速写入数据库，并保留后续分析所需的结构化信息。

表单能力：

- TipTap 富文本编辑器
- 浏览器语音听写插入正文
- 梦境标题
- 梦境发生时间
- 多选情绪标签
- 临时自定义情绪标签
- 清晰度 1-5 星
- 重复梦境标记
- 现实关联记录
- 保存草稿
- 创建梦境

语音听写说明：

- 使用浏览器 Web Speech API。
- 支持中文普通话、粤语和英文。
- 识别到的最终文本会插入富文本正文。
- 不依赖后端 AI API Key。


### 4. 梦境详情 `/dreams/[id]`

功能定位：编辑单条梦境，查看 AI 解析、故事、图片和共享状态。

页面分为两列：

- 左侧：梦境编辑表单。
- 右侧：内容动作、记录信息、AI 解析结果、创意故事与图片。

内容动作：

- 解析梦境
- 生成故事
- 生成图片
- 提交匿名共享
- 导出 Markdown
- 打印 PDF

AI 动作状态：

- 未配置 API Key 时，解析、故事和图片按钮不可用，并引导用户到设置页。
- 已配置 AI 后，请求会创建异步任务。
- 前端轮询任务状态，完成后刷新详情页。

共享状态：

- 未提交
- 待审核
- 已进入共享池
- 未通过




### 5. 时间轴 `/timeline`

功能定位：按时间线浏览梦境记录。

筛选条件：

- 开始日期
- 结束日期
- 情绪
- 清晰度

展示逻辑：

- 先按日期分组。
- 组内保留梦境摘要、情绪、清晰度、状态。
- 点击时间轴项进入详情页。


### 6. 元素图谱 `/elements`

功能定位：把 AI 提取的梦境元素转化为可交互关系图谱。

数据来源：

- `DreamElement` 表。
- 由 AI 解析任务中的 `extractElements` 生成。

元素类型：

- `character`：人物
- `location`：地点
- `object`：物品
- `action`：动作

图谱规则：

- 节点越大，元素出现次数越高。
- 连线越粗，两个元素在同一梦境中共现次数越多。
- 选中或悬停节点时，高亮关联元素。
- 右侧面板展示当前元素、类型、出现次数和关联元素。


### 7. 洞察报告 `/insights`

功能定位：从多条梦境中识别个人模式。

统计范围：

- `ACTIVE`
- `ARCHIVED`

报告模块：

- 总记录数
- 重复梦境数
- 现实关联数
- 高频主题
- 情绪分布
- 常见主题对比
- 压力模式
- 记录建议

主题对比说明：

- 默认主题包括飞行、坠落、追逐、考试、迷路、水域、交通。
- 用户可以在设置页修改主题规则和关键词。
- 洞察报告会使用用户当前启用的主题规则。


### 8. 共享梦境 `/community`

功能定位：匿名分享梦境，并将多个公开梦境串联成公共故事。

共享池展示：

- 审核通过的匿名梦境标题
- 摘要
- 情绪标签
- 主题标签

公共宇宙生成：

- 从公开池中选择 3-5 条梦境。
- 创建 `GENERATE_UNIVERSE` 异步任务。
- Worker 调用 AI 生成 1800-2500 字连贯故事。
- 最近生成的故事会显示在右侧。

审核与脱敏：

- 共享提交会先执行本地规则审核。
- 邮箱、手机号、身份证号、链接、QQ、微信号、长数字等会被隐藏。
- 严重违法、隐私泄露、引流或无效内容会被拒绝或标记复核。



### 9. 设置中心 `/settings`

功能定位：管理账号、运行模式、导出、AI 配置和梦境偏好。

账号摘要：

- 当前账号
- 梦境总数
- 注销账号

导出与保留：

- 下载 Markdown
- 打印 / 保存 PDF

AI API 配置：

- Provider
- API Key
- 聊天 / 解析模型
- 图片模型
- 聊天 Endpoint
- 图片 Endpoint

偏好配置：

- 情绪标签增删
- 主题规则增删
- 主题关键词维护
- 启用 / 停用规则


### 10. 打印报告 `/exports/print`

功能定位：生成适合浏览器打印或保存 PDF 的报告页面。

报告包含：

- 封面信息
- 导出时间
- 梦境总数
- 每条梦境的时间、情绪、清晰度、重复梦境标记
- 梦境内容
- 现实关联
- AI 象征解读
- 情绪分析
- 压力源与主题
- 创意故事


## 主要用户流程

### 记录并解析一条梦境

```text
登录 / 注册
  -> 记录梦境
  -> 文字输入或语音听写
  -> 选择情绪、清晰度、重复梦境
  -> 创建梦境
  -> 进入详情页
  -> 解析梦境 / 生成故事 / 生成图片
  -> 等待任务完成
  -> 查看解析结果和创意输出
```

### 从多条梦境中发现模式

```text
持续记录梦境
  -> 为梦境生成 AI 解析
  -> 元素写入 DreamElement
  -> 打开元素图谱查看共现关系
  -> 打开洞察报告查看主题、情绪和压力模式
```

### 匿名共享与梦境宇宙

```text
梦境详情页
  -> 提交匿名共享
  -> 本地规则审核和隐私脱敏
  -> 审核通过后进入共享池
  -> 在社区选择 3-5 条公开梦境
  -> 生成共享梦境宇宙
```

### 导出个人梦境日记

```text
设置页或详情页
  -> 下载 Markdown
  -> 或打开打印报告
  -> 使用浏览器保存为 PDF
```

## 视觉系统

当前界面采用深色梦境工作台风格，不再使用旧版紫色渐变单页布局。


### 色彩变量

核心变量定义在 `app/globals.css`：

```css
:root {
  --bg: #08141d;
  --bg-soft: #102432;
  --surface: rgba(8, 20, 29, 0.72);
  --surface-strong: rgba(12, 28, 39, 0.9);
  --surface-card: rgba(235, 243, 246, 0.06);
  --line: rgba(255, 255, 255, 0.1);
  --text: #edf5f6;
  --text-muted: rgba(237, 245, 246, 0.7);
  --accent: #ff8c42;
  --accent-2: #6dd3ce;
  --success: #5ac28f;
  --warning: #ffc857;
  --danger: #ff6b6b;
}
```

视觉语义：

- 深蓝黑背景：营造夜间和梦境氛围。
- 橙色主强调：用于主要按钮和关键行动。
- 青色辅助强调：用于链接、图谱、导航和次要高亮。
- 黄色 / 绿色 / 红色：用于提示、成功和危险状态。

### 布局

桌面端：

```text
┌──────────────────────────────────────────────┐
│ 左侧导航 280px │ 主内容区域                   │
│ AppShell      │ Dashboard / Form / Graph ...  │
└──────────────────────────────────────────────┘
```

移动端：

- 主布局改为单列。
- 侧边栏变为页面顶部块。
- 表格、图谱、设置区和详情区全部堆叠展示。
- 按钮组自动换行。

### 面板与卡片

统一组件语义：

- `app-panel`：页面主区块。
- `card`：信息卡、动作卡、报告卡。
- `metric-card`：数字指标。
- `list-card`：梦境列表项。
- `notice`：提示和反馈。
- `danger-zone`：高风险操作区域。

视觉特征：

- 半透明深色表面。
- 18px 模糊背景。
- 柔和边框。
- 大圆角。
- 统一阴影。

### 按钮层级

- `button-primary`：主要动作，如创建梦境、解析、保存设置。
- `button-secondary`：次要动作，如查看洞察、打印、下载。
- `button-ghost`：低强调动作，如提交共享、返回。

按钮状态：

- Hover 轻微上移。
- Disabled 降低透明度并禁用变换。
- AI 未配置时，相关按钮 disabled 并显示说明。

### 标签与状态

- `chip`：情绪、主题、清晰度、重复梦境等轻量信息。
- `status-badge`：梦境状态、共享状态、公开状态。
- `progress-bar`：洞察和高频元素统计。

### 图谱视觉

元素图谱使用 SVG 绘制：

- 背景有雷达式圆环。
- 节点颜色由元素类型决定。
- 选中节点有发光效果。
- 关联线根据共现次数加粗。
- 支持鼠标悬停、点击和键盘选择。


### 打印样式

`@media print` 会隐藏：

- 应用侧边栏
- 打印工具栏

打印文档切换为白底、深色文字、分页友好的报告样式。

## 交互状态

### 空状态

- 无梦境：提示用户记录第一条梦境。
- 无元素：提示先生成 AI 解析。
- 无共享梦境：提示先提交匿名共享。
- 无洞察数据：提示继续记录和解析。

### 只读状态

访客浏览模式下：

- 允许查看体验数据。
- 禁止保存、删除、触发 AI 任务和生成公共宇宙。
- 按钮禁用并显示只读说明。

### AI 未配置状态

- 记录、编辑、时间轴、导出、共享本地审核仍可用。
- 解析、故事和图片生成不可用。
- 页面提示前往设置页配置 AI API。

### 异步任务状态

- 任务入队：显示“任务已加入队列”。
- 轮询中：按钮处于 pending。
- 成功：提示完成并刷新页面。
- 失败：展示后端返回的错误信息。

## 可访问性与响应式

- 主要导航使用语义化链接。
- 图谱节点支持 `role="button"`、`tabIndex` 和键盘方向键选择。
- 表单字段配有标签。
- 颜色对比以深色背景和高亮文本为主。
- 移动端使用单列布局，避免横向滚动。
- 打印页有独立样式，适合 PDF 输出。
