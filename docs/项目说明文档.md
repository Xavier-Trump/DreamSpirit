# DreamSpirit 梦灵项目说明文档

## 一、项目概述

DreamSpirit 梦灵是一款 AI 梦境记录、解析与共享应用。用户可以在醒来后用文字或语音快速记录梦境，补充情绪、清晰度、重复梦境和现实关联等信息，再通过 AI 生成象征解读、情绪分析、创意故事和代表性图片。随着记录增多，系统会沉淀出梦境元素图谱、主题洞察报告，并支持匿名共享梦境到公共池，由 AI 串联成“共享梦境宇宙”故事。

项目从比赛题目“AI 梦境记录与解析器”出发，但最终实现已经从纯前端单页应用扩展为本地可运行的 Next.js 全栈产品。

`【图片占位】` 项目封面图，建议使用应用首页或梦境总览截图，也可以放置项目 Logo + 主界面拼图。

## 二、解决的问题

很多人醒来后会很快忘记梦境，或者对梦境背后的情绪、压力和象征意义感到好奇。传统日记只能保存文字，难以从长期记录中发现模式。DreamSpirit 希望解决三个问题：

1. 快速记录：用富文本和浏览器语音听写降低记录门槛。
2. 深度理解：用 AI 从象征、情绪、压力源、主题和元素等角度解析梦境。
3. 长期观察：通过时间轴、元素图谱和洞察报告发现反复出现的个人模式。

## 三、目标用户

- 经常做梦、希望保留梦境细节的人。
- 对心理学、神秘学、潜意识探索感兴趣的人。
- 想把梦境转化为故事、诗性文本或视觉灵感的创作者。
- 希望通过长期记录观察压力、情绪和生活事件关联的人。

## 四、核心功能模块

### 1. 梦境记录

- TipTap 富文本编辑器。
- 浏览器语音听写，支持中文普通话、粤语和英文。
- 梦境发生时间。
- 多选情绪标签。
- 临时自定义情绪标签。
- 清晰度 1-5 星。
- 重复梦境标记。
- 现实关联记录。
- 草稿与正式记录状态。
- 编辑页 15 秒自动保存草稿。

`【图片占位】` 梦境记录功能截图，建议突出富文本编辑器、语音听写、情绪标签和清晰度。

### 2. AI 梦境解析

AI 会围绕单条梦境生成：

- 象征解读。
- 情绪分析。
- 潜在压力源。
- 主题标签。
- 模式信号。
- 人物、地点、物品、动作等关键元素。

解析结果会写入数据库，后续用于详情展示、元素图谱和洞察报告。

`【图片占位】` AI 解析结果截图，建议展示象征解读、情绪分析、压力源和主题标签。

### 3. 创意故事与图片

- 单条梦境可生成 300-500 字短篇故事或诗性散文。
- 单条梦境可生成一张代表性图片。
- 图片结果保存为素材记录，详情页可直接查看。

`【图片占位】` 创意故事与梦境图片截图，建议展示故事正文和生成图片。

### 4. 时间轴浏览

- 按日期分组展示梦境。
- 支持日期范围筛选。
- 支持情绪筛选。
- 支持清晰度筛选。
- 点击时间轴条目进入详情。

`【图片占位】` 时间轴页面截图，建议展示筛选栏和日期分组。

### 5. 梦境元素图谱

- AI 自动提取关键元素。
- 节点代表元素，大小代表出现频率。
- 连线代表元素在同一梦境中的共现关系。
- 支持悬停、点击和键盘选择。
- 侧栏展示当前元素及其关联元素。

`【图片占位】` 元素图谱截图，建议展示节点、连线、tooltip 和右侧元素信息。

### 6. 洞察报告

- 统计总记录、重复梦境、现实关联数量。
- 展示高频主题。
- 展示情绪分布。
- 与常见梦境主题进行对比。
- 聚合压力模式。
- 根据记录情况给出建议。
- 用户可在设置页自定义主题规则。

`【图片占位】` 洞察报告截图，建议展示高频主题、情绪分布和压力模式。

### 7. 匿名共享梦境

- 用户可将单条梦境提交匿名共享。
- 提交前执行本地规则审核。
- 自动隐藏邮箱、手机号、身份证号、链接、QQ、微信号等隐私信息。
- 审核通过后进入共享梦境池。
- 社区页可浏览他人的匿名梦境摘要。

`【图片占位】` 匿名共享审核截图，建议展示共享状态、审核说明或社区公开池。

### 8. 共享梦境宇宙

- 从公开梦境池选择 3-5 条梦境。
- AI 生成 1800-2500 字连贯公共故事。
- 最近生成的公共故事在社区页展示。

`【图片占位】` 共享梦境宇宙截图，建议展示公开梦境选择和生成故事结果。

### 9. 导出与报告

- 全量 Markdown 导出。
- 打印版梦境报告。
- 浏览器可将打印页保存为 PDF。

### 10. 设置与本地运行体验

- 用户级 AI API 配置。
- 情绪标签与主题规则配置。
- 本机离线 / 局域网访问说明。
- Windows 一键启动脚本。
- seed 体验数据。

## 六、技术实现

### 技术栈

- Next.js App Router
- React
- TypeScript
- PostgreSQL
- Prisma
- Auth.js Credentials
- TipTap
- lucide-react
- zod
- bcryptjs

`【图片占位】` 技术架构图，可用一张流程图展示 Next.js 前端、API、PostgreSQL、Worker 和 AI Provider 的关系。

### 架构特点

1. 前端不直连大模型。
   浏览器只请求本项目 API，不保存真实 API Key。

2. AI 调用走服务端任务队列。
   解析、故事、图片、共享审核、宇宙故事都以 `Job` 入队，由 Worker 异步执行。

3. 数据持久化。
   梦境、解析、故事、图片、元素、共享状态、审核结果和任务状态都保存在 PostgreSQL。

4. 用户级配置。
   每个用户可以在设置页保存自己的 AI API 配置，环境变量作为兜底。

5. 本地优先。
   项目默认在本机运行，数据存放在本机数据库，适合比赛演示和个人使用。

## 七、数据流说明

### 记录梦境

```text
用户填写表单
  -> POST /api/dreams
  -> 校验数据
  -> 写入 Dream
  -> 跳转详情页
```

### AI 解析

```text
点击解析梦境
  -> POST /api/dreams/:id/analyze
  -> 创建 ANALYZE_DREAM Job
  -> Worker 调用 AI Provider
  -> 写入 DreamAnalysis 和 DreamElement
  -> 前端轮询任务完成
  -> 刷新详情页
```

### 匿名共享

```text
点击提交匿名共享
  -> 创建 MODERATE_SHARE Job
  -> 本地规则审核与隐私脱敏
  -> 写入 SharedDream 和 ModerationReview
  -> 审核通过后显示到社区页
```

### 生成公共宇宙

```text
选择 3-5 条公开梦境
  -> POST /api/community/universe
  -> 创建 GENERATE_UNIVERSE Job
  -> Worker 调用 AI 生成故事
  -> 写入 UniverseStory
  -> 社区页展示
```

## 八、创新点

1. 梦境不是单条孤立记录。
   系统会通过图谱和报告把长期记录连接起来，形成个人梦境模式。

2. 匿名共享前置安全处理。
   在进入公共池之前先做本地规则审核和隐私脱敏，降低公开内容风险。

3. 用户可调主题规则。
   常见梦境主题不是写死在报告里，用户可以维护自己的主题关键词。

4. 本地可运行的全栈体验。
   不依赖云数据库或云部署，便于演示、迁移和个人保存。

5. AI 能力异步化。
   长耗时 AI 请求不阻塞页面，任务状态可查询，失败可重试。

## 九、运行与演示

### 安装依赖

```bash
npm install
```

### 启动数据库

```bash
docker compose up -d
```

### 初始化数据库

```bash
npx prisma db push
npm run prisma:seed
```

### 启动 Web

```bash
npm run dev
```

### 启动 Worker

```bash
npm run worker
```
